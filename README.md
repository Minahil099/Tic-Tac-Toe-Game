# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe game** built using **HTML, CSS, and JavaScript**.

## 🚀 About This Project

This project is a browser-based Tic Tac Toe game created to practice **JavaScript fundamentals** and improve my frontend development skills.

### 🎯 Features

* **Two-player gameplay**
* **Interactive game board**
* **Win detection**
* **Draw detection**
* **Game reset functionality**
* **Responsive and simple UI**

### 💡 Concepts Practiced

* **JavaScript Variables & Functions**
* **Conditional Statements**
* **Arrays**
* **DOM Manipulation**
* **Event Handling**
* **Game Logic**
* **HTML & CSS Styling**

## 🛠️ Technologies

**HTML5 • CSS3 • JavaScript**

## 🎓 Purpose

This project was created as part of my **frontend web development learning journey** to practice JavaScript logic and DOM manipulation through a real interactive project.
